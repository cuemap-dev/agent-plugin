# Changelog

## [0.7.5] - 2026-10-14

### Changed
- Pins `cuemap-mcp@0.7.5`.
- The `cuemap-memory` skill recommends leaving `expansion_depth` unset so recall uses the engine's conversation-round default.

## [0.7.3] - 2026-08-28

### Added

- Initial standalone Agent Plugins 1.0.0 package for CueMap.
- Added the stdio MCP configuration pinned to `cuemap-mcp@0.7.3`.
- Added the `cuemap-memory` skill for repository initialization, explicit ingestion, status monitoring, and project-scoped recall.
- The bundled skill documents project residency controls, including automatic inactivity unloading, explicit project load/unload, and demand-loading behavior.
